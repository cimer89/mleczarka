# Mleczarka

Gra o prowadzeniu mleczarni na Podlasiu — Unity 6.3 LTS (6000.3.28f1), URP.

## Chcę tylko zagrać (Windows, bez Unity)
Pobierz `Mleczarka_Windows.zip` z [Releases](https://github.com/cimer89/mleczarka/releases/latest), rozpakuj i uruchom `Mleczarka.exe`. Szczegóły: **[INSTALACJA.md](INSTALACJA.md)**.

## Jak uruchomić w Unity (edycja gry)
0. Zainstaluj Unity Hub (https://unity.com/download) i edytor **6000.3.28f1** (Hub → Installs → Install Editor albo https://unity.com/releases/editor/archive). Projekt pobierz: zielony przycisk **Code → Download ZIP** albo GitHub Desktop → Clone.
1. Unity Hub → Add → wskaż ten folder → otwórz w Unity 6000.3.28f1.
2. Pierwsze otwarcie trwa dłużej: Unity buduje folder `Library` (nie ma go w repozytorium).
3. Scena główna: `Assets/_Mleczarka/Scenes/Gmina_Podlasie.unity` → Play.
4. Menu startowe: „Kontynuuj grę” albo „Nowa gra od początku”.

## Stan
Aktualny stan, zakres i wyniki testów: `PROJECT_STATUS.md`. Historia: `CHANGELOG.md`.

## Zasoby
Modele i animacje zewnętrzne: Quaternius i Kenney (CC0). Maszyny mleczarni: własne modele z Blendera (`Blender/`). Licencje w folderach paczek w `Assets/_Mleczarka/Art/ThirdParty`.
